1. Causal Decoder vs Encoder

Jev acts encoder-like, but Hume concludes it is a causal transformer decoder (likely sparse MoE with ~10B active parameters out of 70B+). 30k tokens were processed in ~160ms. MMLU-Pro accuracy is 84.6%, indicating massive pretraining weights.

2. Listwise Option Cross-Attention

When an irrelevant 5th option ("weather caused it") was added to a 4-option set, the log-odds between existing options shifted by -0.28 across 10 randomized blocks. This proves options attend to each other, resolving contextual terms like "none of the above".

3. Context Limits & Token Accounting

Max branch length: 32,768 tokens (2¹⁵).
Max total packed request: 65,536 tokens (2¹⁶).
State is counted once: a 23k-token state with 1,000 questions fits in one call without duplicating context.

4. RLCD: Proper Scoring Rule

Trained via proper scoring rules (Brier loss & log-loss). On a 1,200-item MMLU sample, Jev achieved an Expected Calibration Error (ECE) of 0.0313, fixing standard LLM overconfidence.

Laya & Kev: Running System 1 Locally

Laya (ConvAI Innovations) Apache 2.0

Created by Nandakishor Mukkunnoth. Grounded in his March 2025 (arXiv:2503.23303) and Sept 2025 (arXiv:2510.01237) non-autoregressive decision papers.

  • Latency: 32.8 ms (7.2 ms per question batched) on single T4 GPU.
  • Base: ModernBERT-large (421M params). Bidirectional encoder.
  • Languages: 100+ languages verified across a 51-language sweep.
  • Cost: $0.0029 per 1k decisions (0.07× Jev cost).
pip install laya
Kev (Jared Palmer) Apache 2.0

Built directly on Qwen 3.5 and Qwen 3.8 base weights using Archer Hume's reverse-engineering blueprint.

  • Sizes: Kev-0.8B (runs on Mac/laptop), 4B, 9B, and Kev-27B.
  • Unseen Task Accuracy: Kev-27B hits 89.6% (Brier score 0.164), surpassing hosted Jev (85.7%).
  • Compatibility: Native drop-in for TypeSafe's Python SDK via /v1/systemone.
uv run python -m kev.serve --run jaredpalmer/kev-4b

Documented Limits of Jev 1.13
  • Reads literally: Put boundary conditions directly into criteria; cannot infer unstated nuances.
  • Not a calculator: Math, counting, and date arithmetic fail consistently. Keep math in code.
  • State noise sensitivity: Adding irrelevant text to state significantly lowers classification accuracy.
  • Prompt injection vulnerability: Malicious text in state can bias probabilities if questions lack defensive framing.
  • No explanations: Returns only a label and probability; no reasoning trace to audit.
